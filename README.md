# Алгебра, 7 класс — диагностическая работа

Страница: https://asteisesdev-org.github.io/matematika/

Четыре части по 30–40 минут: фундамент 5–6 класса, выражения и преобразования,
уравнения и задачи, функции и графики. Задания подобраны так, чтобы по неверному
ответу была видна причина ошибки.

Страница самодостаточна: один `index.html` без внешних зависимостей. Ответы хранятся
только в браузере ученика (localStorage) и никуда не отправляются; передать их можно
кнопкой «Скопировать ответы». Ответов к заданиям в этом репозитории нет.

Публикуется через GitHub Pages из ветки `main` — изменения появляются на странице
через минуту-две после пуша.
